# 智能化工业设施风险检测系统 · 技术方案（脱敏版）

> 依据校企立项任务书公开技术路线整理；已删除企业名/预算/密级/进度责任人等涉密字段。
> 供复现、参赛、论文转化的通用技术参考。

---

## 1. 总体目标

以深度学习为基础的工业设备智能风险识别：机器视觉（无人机 + 固定摄像头）+ 缺陷检测模型，
对线缆槽盒盖缺失、管道受损、材料堆坍塌等隐患实现高精度、实时化监测；
配合边缘计算与数据融合，形成"采集 → 训练 → 部署 → 预警 → 报告"全流程方案，
替代传统人工巡检。

## 2. 场景与需求

| 需求 | 细节 |
|---|---|
| 输入 | 多段工业监控视频/图像（同区域不同时间拍摄，如每日无人机巡检） |
| 变化/缺陷检测 | 槽盒盖缺失、管道受损、料堆坍塌；区分有意义变化与光照/人员干扰 |
| 定位与标记 | bbox/轮廓标记 + 叠加可视化输出 |
| 报告 | 生成变化报告（时间/位置/类型），支持人工复核 |
| 指标 | 以 IoU@0.5 计 Precision/Recall；关注漏检率 FNR |
| 性能 | 近实时推理；适应光照变化、动态干扰 |

## 3. 数据方案（脱敏）

- 原生产数据受协议保护，不随仓库发布。
- **演示/公开验证数据建议**：
  - 钢/金属表面缺陷：`NEU-DET`（热轧钢表面 6 类缺陷，公开）
  - 线缆/工业设施：Roboflow Universe 搜索 `cable tray` / `pipe defect` / `industrial inspection` 公开数据集
  - 料堆/场景变化检测：公开"变化检测"数据集（如 LEVIR-CD / 工业视频监控数据集）
- 标注格式：YOLO txt（class cx cy w h）；本仓库提供 `scripts/prepare_data.py` 做格式转换引导
- 类别定义模板见 `data/defects_sample.yaml`（槽盒盖缺失/管道损伤/材料塌陷等可自由映射）

## 4. 算法选型（脱敏提炼）

检测基座（推荐，可复用开源改进）：

| 组件 | 可选改进（对应任务书方向） | 说明 |
|---|---|---|
| Backbone | Ghost / MobileNetV3 / ConvNeXt V2 / FocalNet | 轻量化、边缘部署友好 |
| 注意力 | SE / CBAM / BiFormer / 三重注意力 | 光照变化与复杂背景鲁棒 |
| Neck | 改进特征金字塔（如 FDPN/HSFPN 类） | 多尺度融合 |
| Head | DyHead 类 + LSDECD 类可变形卷积头 | 适应不同尺寸/角度目标 |
| Loss | MPDIoU / PolyLoss / Wasserstein | 小目标与难样本 |

> 已开源引擎 `rail-surface-defect-yolo11` 提供 LSDECD 检测头 + FDPN + ODConv + 通道剪枝的具体实现，
> 可直接作为检测基座做迁移训练。

## 5. 边缘部署

1. `export_onnx.py`：`best.pt → best.onnx`（imgsz=640，dynamic batch 可选）
2. 平台适配：
   - 瑞芯微 RK3588/RK3568：`rknn-toolkit2` 转 `.rknn`（INT8/FP16 量化）
   - 英伟达 Jetson：TensorRT（FP16/INT8）
   - 普通边缘盒：ONNX Runtime（CPU/INT8）
3. 量化要点：先校准集统计动态范围；INT8 通常 mAP 损失 <2%（参考剪枝要求口径）

## 6. 系统输出

- 检测叠加视频/图像 + 风险报告（时间/位置/类型/置信度）
- 支持人工复核与误报回退
