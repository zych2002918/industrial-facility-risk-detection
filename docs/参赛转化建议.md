## 一、作品定位

**智能工业设施巡检与缺陷检测系统**：无人机/固定摄像头采集 → YOLO 改进缺陷检测
（槽盒盖缺失/管道受损/材料坍塌）→ 边缘部署 + 风险报告。
技术栈与已开源 `rail-surface-defect-yolo11`（LSDECD+FDPN+ODConv+剪枝）同源，可复用其
改进模型与权重做迁移训练，工程成本低、演示效果好。
